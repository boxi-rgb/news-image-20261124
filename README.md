24 November 2026: Nvidia bringing Jensen Huang back as CEO, NATO sending
an AWACS early-warning jet to Poland, Iran flogging singer Parastoo Ahmadi,
two US states suing Musk's companies over Grok sex images, Rep. Jimmy Gomez
resigning, the COP31 fallout, the UN chief's call for global AI safety rules,
and more.

## Run it

```sh
python3 draw.py
```

`draw.py` draws `entry.png` (1024×1024) from scratch with Pillow — every
text block is measured first and the script fails rather than overflowing.
`main.ts` runs `draw.py` and copies the image to the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).
